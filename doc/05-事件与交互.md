# 05 · 事件与交互

本章说明控件回调的触发方式、`GuiActionEvent` 的取值方法、`updateWidget` 能改哪些属性，以及窗口关闭 / Esc 的完整行为。控件本身的链式 API 见 [03-基础控件](03-基础控件.md) 与 [04-表单控件](04-表单控件.md)。

## 5.1 事件模型

客户端把点击、拖动、输入等操作打包成事件发给服务端；服务端收到后**统一调度到主线程**再执行回调，因此可以在回调里直接调用 Bukkit API、修改背包、发送消息、打开新窗口。

每个事件对应一个控件，通过 `GuiWindow.addXxx(...)` 返回的控件对象注册回调：

| 回调注册方法 | 所属控件 | action |
| --- | --- | --- |
| `onClick(Consumer<GuiActionEvent>)` | `Button`、`Panel`、`ImageWidget`、`ItemWidget` | `click` |
| `onChange(Consumer<GuiActionEvent>)` | `TextField`、`Slider` | `text` / `change` |
| `onToggle(Consumer<GuiActionEvent>)` | `Checkbox`、`Radio` | `toggle` |
| `onSelect(Consumer<GuiActionEvent>)` | `Dropdown` | `select` |
| `onEscape(Consumer<GuiActionEvent>)` | `GuiWindow` | `esc` |

实际会出现的 action 字符串共 7 种：`click`、`change`、`toggle`、`select`、`text`、`close`、`esc`。其中 `close` 不会进入任何控件回调，只触发窗口关闭钩子（见 5.5）。

### GuiActionEvent

`com.guiapi.paper.GuiActionEvent` 是回调参数，提供以下方法：

| 方法签名 | 返回 | 说明 |
| --- | --- | --- |
| `Player player()` | `Player` | 触发事件的玩家 |
| `GuiWindow window()` | `GuiWindow` | 事件所属窗口 |
| `Widget widget()` | `Widget` | 触发事件的控件；`esc` 事件为 `null` |
| `String action()` | `String` | 动作字符串，见上表 |
| `JsonElement rawValue()` | `JsonElement` | 原始值；无值的事件为 `null` |
| `String valueAsString()` | `String` | 按字符串取值；`null` 返回 `""` |
| `int valueAsInt()` | `int` | 按下标/整数取值；`null` 返回 `0` |
| `double valueAsDouble()` | `double` | 按数值取值；`null` 返回 `0` |
| `boolean valueAsBoolean()` | `boolean` | 按布尔取值；`null` 返回 `false` |

> `valueAsString()` 对数字类型返回的是数字的字符串形式，不能把下拉框的下标当成选项文本使用。

### 所有控件事件总表

| 控件 | 回调 | action | value | 服务端自动同步的字段 |
| --- | --- | --- | --- | --- |
| `Button` | `onClick` | `click` | 无 | — |
| `Panel` | `onClick` | `click` | 无 | — |
| `ImageWidget` | `onClick` | `click` | 无 | — |
| `ItemWidget` | `onClick` | `click` | 无 | — |
| `TextField` | `onChange` | `text` | `String` | `text(...)` |
| `Slider` | `onChange` | `change` | `double` | `value(...)` |
| `Checkbox` | `onToggle` | `toggle` | `boolean` | `checked(...)` |
| `Radio` | `onToggle` | `toggle` | `boolean`（恒为 `true`） | 不同步 |
| `Dropdown` | `onSelect` | `select` | `int`（下标） | `selected(...)` |
| `GuiWindow` | `onEscape` | `esc` | 无 | — |

“服务端自动同步”指事件到达时插件会先更新该控件对象的对应字段，再调用回调；`Radio` 例外，需要自行记录选中项。

## 5.3 点击与交互细节

### 哪个窗口接收点击

- 鼠标点击时，从最上层的窗口开始向下查找；只有**光标所在的最上层窗口**接收输入。
- 点击一个窗口会把该窗口提升到最前（`alwaysOnTop(true)` 的窗口始终保持在普通窗口之上）。
- 窗口背景本身会消费点击，点空白处不会穿透到下面的窗口。
- 鼠标悬停高亮、tooltip 也只对最上层窗口生效。

### 控件命中

- `visible(false)` 的控件不绘制、不悬停、不接收点击。
- `Button`、`ItemWidget`：整个矩形都接收点击。
- `Panel`、`ImageWidget`：只有调用了 `onClick(...)` 的实例才会被标记为可点击；未注册回调时点击会穿透到窗口背景。
- `Checkbox`、`Radio`：只有左侧方框加文字的范围（宽 `16 + 文字宽度`、高 `12`）接收点击。
- `Slider`：只有轨道附近（高 14 像素）接收点击和拖动。
- `Dropdown`：点击收起框（高 18）展开/收起；展开后的选项列表绘制在窗口之上，可以超出窗口范围，点击选项后自动收起；点击列表外任意位置也会收起。
- 展开的下拉列表支持鼠标滚轮，超过 6 项时可滚动。

### 拖动与点击的冲突

设置了 `dragGroup(...)` 的控件属于横向拖动组：

- 按下时不会立刻触发点击，而是先记录为“待点击”；
- 松开时如果指针移动未超过约 3 像素，才补发 `click`；
- 一旦发生拖动，本次松开不会触发点击，避免拖动整排手牌时误选卡牌；
- 只有整组宽度超出窗口时才可拖动，且不能拖到起始位置右侧。

### 输入框焦点

- 点击输入框获得焦点并显示光标。
- 按 Enter 或点击输入框外任意位置都会提交内容并发 `text` 事件。
- 输入框聚焦时按 Esc 只会提交内容并取消焦点，**不会关闭窗口**。
- `live(true)` 时每次击键都发送一次 `text` 事件；默认 `false`，只在 Enter / 失焦时发送。

### 滑块

- 拖动过程中只更新客户端显示，不发送事件。
- 松开鼠标时发送一次 `change` 事件，值为最终数值。
- 结果会按 `step` 取整并夹在 `min` / `max` 之间；`step <= 0` 时不取整。

### 悬停与动画

- `tooltip(...)` 只影响显示，不产生事件。
- `hoverLift(true)` 只让控件在视觉上上抬约 3 像素，点击判定仍在原位置。
- `glow(...)`、`anim(...)` 同样不产生事件。

## 5.4 updateWidget 可改字段

### 方法签名

```java
public void updateWidget(Player player, String windowId, String widgetId, Map<String, Object> properties)
```

用于修改一个**已经打开**窗口里的控件属性，常用于刷新文字、数值、选中态、显隐和颜色，而不必重新 `openWindow`。

```java
GuiApi.get().updateWidget(player, "shop", "price", Map.of("text", "价格：128"));
```

值支持 `Number`、`Boolean`、`List<?>` 和 `String`；`List` 会按字符串数组发送（适合 `options`、`lore`、`enchants`）。窗口或控件 id 不存在时静默忽略。

### 通用注意

- **只改客户端显示。** 服务端 `GuiWindow` 里的控件对象不会自动同步（事件回调中的 `Slider.value()`、`Checkbox.checked()`、`Dropdown.selected()`、`TextField.text()` 除外），需要以你自己的服务端变量为准。
- **颜色必须传整数 ARGB。** 例如 `0xFFFFD166`。传 `"#FFD166"` 这类字符串不会被解析成颜色，属性会失效。
- **不要传 `null`。** 需要清空提示可用 `""`。
- **`type`、`id` 不可改。** 事件分发仍按原控件类型和 id 进行；需要换控件类型请重新 `openWindow`。
- 布局类属性（`x`、`y`、`w`、`h`、百分比、`aspect`、`visible`）修改后会立即生效；若控件设置了 `animMs`，位置变化会按补间动画滑过去。
- 列表属性会整体替换，不是追加。

### 通用属性（所有控件）

| 属性名 | 类型 | 说明 |
| --- | --- | --- |
| `visible` | `boolean` | 显示 / 隐藏；隐藏后不可点击 |
| `x` / `y` | `int` | 绝对坐标；负值表示从内容区中心偏移 |
| `w` / `h` | `int` | 宽高；负宽/负高表示贴右/下边缘留边距 |
| `xPct` / `yPct` | `double` | 横向 / 纵向百分比，和 `x`、`y` 偏移叠加 |
| `wPct` / `hPct` | `double` | 宽度 / 高度百分比，和 `w`、`h` 偏移叠加 |
| `aspect` | `double` | 宽高比；设置后高度由宽度推导，优先于 `hPct` |
| `tooltip` | `String` | 悬停提示；`""` 可清除 |
| `glowColor` | `int` ARGB | 高亮描边颜色 |
| `hoverLift` | `boolean` | 悬停上抬 |
| `dragGroup` | `String` | 拖动组名；`""` 取消分组 |
| `animMs` | `int` | 补间时长；`<= 0` 用默认平滑跟随 |
| `animEase` | `String` | `linear` / `in` / `out` / `inOut` |

### 示例：动态刷新列表

```java
void openPlayerList(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("list_demo").title("在线玩家").size(300, 220);

    for (int i = 0; i < 5; i++) {
        window.addLabel("row" + i, 20, 20 + i * 20, "")
                .color(0xFFFFFFFF)
                .visible(false);
    }

    api.openWindow(player, window);
    refreshRows(player, List.of("Alice", "Bob", "Carol"));
}

void refreshRows(Player player, List<String> names) {
    GuiApi api = GuiApi.get();
    for (int i = 0; i < 5; i++) {
        if (i < names.size()) {
            api.updateWidget(player, "list_demo", "row" + i,
                    Map.of("visible", true,
                           "text", names.get(i),
                           "color", 0xFFFFD166));
        } else {
            api.updateWidget(player, "list_demo", "row" + i,
                    Map.of("visible", false));
        }
    }
}
```

下拉框换选项时同时更新下标：

```java
api.updateWidget(player, "list_demo", "fruit",
        Map.of("options", List.of("西瓜", "葡萄"), "selected", 0));
```

## 5.5 窗口关闭与 Esc

### 触发来源

| 操作 | 条件 | 客户端行为 | 服务端收到 |
| --- | --- | --- | --- |
| 标题栏右上角关闭按钮 | `titleBar(true)`（默认）且 `closeOnEsc(true)`（默认） | 关闭该窗口 | `close` |
| 标题栏右上角关闭按钮 | `closeOnEsc(false)` | 不关闭，发事件 | `esc` |
| Esc | 输入框正在聚焦 | 提交输入框内容、取消焦点 | `text`（不关窗口） |
| Esc | 最上层窗口 `closeOnEsc(false)` | 不关闭，发事件 | `esc` |
| Esc | 最上层窗口 `closeOnEsc(true)` | 关闭**全部** GuiApi 窗口 | 每个窗口各一条 `close` |

结论：

- 默认 `closeOnEsc(true)` 时，Esc 会一次性关闭所有已打开的 GuiApi 窗口，不只是最上层那个。
- `closeOnEsc(false)` 时，Esc 和标题栏关闭按钮都只会发送 `esc`，窗口保持打开，由服务端决定下一步。
- 输入框聚焦时 Esc 被输入框“吃掉”，只提交文本，不会关闭窗口，也不会发送 `esc`。

### close 事件

`close` 来自客户端主动关闭（标题栏按钮或 Esc）。服务端处理时：

1. 从该玩家的已打开窗口表中移除这个窗口；
2. 调用通过 `GuiApi.onWindowClosed(windowId, hook)` 注册的钩子。

```java
public void onWindowClosed(String windowId, Consumer<GuiWindow> hook)
```

```java
GuiApi api = GuiApi.get();
api.onWindowClosed("exit_confirm", window -> {
    // 注意：钩子只有 GuiWindow 参数，没有 Player
    // 适合做与玩家无关的清理；按玩家清理请使用自己的会话表或 PlayerQuitEvent
});
```

- 钩子按 **window id** 全局注册，同一个 id 的所有玩家共用；没有 per-player 参数。
- 传入 `null` 可以移除该 id 的钩子。
- 服务端主动调用 `GuiApi.closeWindow(player, id)` 不会触发这个钩子，也不会产生 `close` 事件。

### esc 事件

当 `closeOnEsc(false)` 时注册 `onEscape`：

```java
GuiWindow window = new GuiWindow("confirm")
        .closeOnEsc(false)
        .onEscape(e -> e.player().sendMessage("已取消"));
```

- `esc` 事件的 `widget()` 为 `null`，`window()` 与 `player()` 正常可用。
- 是否真的关闭窗口由你决定：可以调用 `GuiApi.closeWindow(...)`，也可以保持窗口并提示玩家。
- 关闭按钮在 `closeOnEsc(false)` 时同样走 `esc`，所以需要给玩家一个能真正关闭的按钮。

### 示例：按 Esc 先确认

```java
void openExitConfirm(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("exit_confirm")
            .title("退出")
            .size(280, 150)
            .closeOnEsc(false)
            .onEscape(e -> e.player().sendMessage("已取消退出"));

    window.addLabel("msg", 20, 24, "确定要退出当前界面吗？").color(0xFFE8EFF7);

    window.addButton("leave", 20, 80, 110, 22, "退出")
            .onClick(e -> api.closeWindow(e.player(), "exit_confirm"));

    window.addButton("stay", 150, 80, 110, 22, "留下")
            .onClick(e -> api.updateWidget(e.player(), "exit_confirm", "msg",
                    Map.of("text", "已取消，窗口保持打开")));

    api.openWindow(player, window);
}
```

## 5.6 交互自查清单

- 每个需要点击的 `Panel` / `ImageWidget` 都调用了 `onClick(...)`，否则点击会穿透。
- 子类方法写在基类方法之前，避免链式调用丢失子类类型。
- 下拉框用 `valueAsInt()` 取下标，再用 `options.get(index)` 取文本。
- 输入框需要逐字过滤时才开 `live(true)`，否则保持默认以减少数据包。
- 用 `updateWidget` 改颜色时传整数 ARGB，不传 `#RRGGBB` 字符串。
- 不要依赖 `updateWidget` 同步服务端控件对象，状态请自己保存。
- 使用 `closeOnEsc(false)` 时，务必提供可真正关闭窗口的按钮。
- 客户端主动关闭后在 `GuiApi.onWindowClosed(...)` 里做清理；服务端 `closeWindow` 不会触发该钩子。
