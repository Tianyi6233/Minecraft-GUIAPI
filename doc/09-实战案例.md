## 9.0 公共骨架

所有案例都假设你已经完成了下面几件事：

- `plugin.yml` 声明 `depend: [GuiApi]`（或 `softdepend`）；
- 在 `onEnable()` 里 `GuiApi api = GuiApi.get();`；
- 图片 / 音效在 `onEnable` 注册一次；
- 玩家上线或开局时 `preloadImage` / `preloadSound`。

```java
import com.guiapi.paper.GuiApi;
import org.bukkit.plugin.java.JavaPlugin;

import java.io.IOException;
import java.io.InputStream;
import java.util.List;

public abstract class DemoPluginBase extends JavaPlugin {

    /** 案例里用到的图片 id 后缀，真实项目按素材表维护。 */
    protected static final List<String> IMAGES = List.of(
            "bg", "card_skip", "card_bomb", "boom_l", "boom_r", "table");

    /** 案例里用到的音效 id 后缀。 */
    protected static final List<String> SOUNDS = List.of(
            "click", "bgm", "boom");

    protected GuiApi api;

    @Override
    public void onEnable() {
        api = GuiApi.get();
        for (String name : IMAGES) {
            byte[] png = read("assets/demo/" + name + ".png");
            if (png.length > 0) api.registerImage(imageId(name), png);
        }
        for (String name : SOUNDS) {
            byte[] ogg = read("assets/demo/sounds/" + name + ".ogg");
            if (ogg.length > 0) api.registerSound(soundId(name), ogg);
        }
        api.setClickSound(soundId("click"), 0.7f);
    }

    /** 所有资源 id 加插件前缀，避免与其他插件冲突。 */
    protected static String imageId(String name) {
        return "demo_" + name;
    }

    protected static String soundId(String name) {
        return "demo_" + name;
    }

    /** 开局 / 登录时一次性预热，避免第一次出现时才传输。 */
    protected void preload(org.bukkit.entity.Player player) {
        for (String name : IMAGES) api.preloadImage(player, imageId(name));
        for (String name : SOUNDS) api.preloadSound(player, soundId(name));
    }

    private byte[] read(String path) {
        try (InputStream in = getResource(path)) {
            if (in == null) {
                getLogger().warning("缺少资源: " + path);
                return new byte[0];
            }
            return in.readAllBytes();
        } catch (IOException e) {
            getLogger().warning("读取资源失败: " + path);
            return new byte[0];
        }
    }
}
```

后面的案例都继承 `DemoPluginBase`，直接用 `api`、`imageId(...)`、`soundId(...)`、`preload(...)`。如果你已经有自己的插件主类，把这几行搬进去即可。

## 9.1 案例一：聊天可点击邀请，接受后开窗

### 场景

房主在聊天框点 `[同意]`，以玩家身份执行一条命令；命令处理里校验邀请，然后打开队伍界面。

### 用到的 API

| API | 用途 |
| --- | --- |
| Adventure `Component` + `ClickEvent.runCommand` | 聊天里的可点击按钮 |
| `api.isClientSupported(player)` | 双方都必须装客户端模组 |
| `api.openWindow(player, window)` | 接受后展示队伍窗口 |
| `api.playSound(...)` | 点击反馈 |

### 代码

```java
import com.guiapi.paper.GuiApi;
import com.guiapi.paper.GuiWindow;
import net.kyori.adventure.text.Component;
import net.kyori.adventure.text.event.ClickEvent;
import net.kyori.adventure.text.event.HoverEvent;
import net.kyori.adventure.text.format.NamedTextColor;
import org.bukkit.command.Command;
import org.bukkit.command.CommandSender;
import org.bukkit.entity.Player;

import java.util.Set;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

public final class PartyInviteDemo extends DemoPluginBase {

    private static final String WINDOW_PARTY = "demo_party";

    /** 简化：只记录“被邀请过的人”。真实项目按 partyId + 邀请人做多房间。 */
    private final Set<UUID> invited = ConcurrentHashMap.newKeySet();

    /** 房主邀请某人：先检查对方有没有装模组，再发可点击消息。 */
    void invite(Player leader, Player target) {
        if (!api.isClientSupported(target)) {
            leader.sendMessage("§c对方没有安装 GuiApi 客户端模组，无法加入");
            return;
        }
        if (!invited.add(target.getUniqueId())) {
            leader.sendMessage("§c已经邀请过了");
            return;
        }

        target.sendMessage(Component.text("[组队] ", NamedTextColor.AQUA)
                .append(Component.text(leader.getName() + " 邀请你加入队伍  ", NamedTextColor.WHITE))
                .append(Component.text("[ 同意 ]", NamedTextColor.GREEN)
                        .clickEvent(ClickEvent.runCommand("demo accept " + leader.getName()))
                        .hoverEvent(HoverEvent.showText(Component.text("点击加入队伍"))))
                .append(Component.text("   "))
                .append(Component.text("[ 拒绝 ]", NamedTextColor.RED)
                        .clickEvent(ClickEvent.runCommand("demo deny " + leader.getName()))
                        .hoverEvent(HoverEvent.showText(Component.text("点击拒绝")))));
    }

    @Override
    public boolean onCommand(CommandSender sender, Command command, String label, String[] args) {
        if (!(sender instanceof Player player) || args.length < 2) return true;

        switch (args[0].toLowerCase()) {
            case "accept" -> {
                // 必须服务端再校验一次：聊天点击本质上就是执行命令，参数不可信
                if (!invited.remove(player.getUniqueId())) {
                    player.sendMessage("§c邀请已失效");
                    return true;
                }
                if (!api.isClientSupported(player)) {
                    player.sendMessage("§c需要安装 GuiApi 客户端模组");
                    return true;
                }
                preload(player);
                openParty(player, args[1]);
            }
            case "deny" -> {
                invited.remove(player.getUniqueId());
                player.sendMessage("§7已拒绝邀请");
            }
            default -> { }
        }
        return true;
    }

    private void openParty(Player player, String leaderName) {
        GuiWindow window = new GuiWindow(WINDOW_PARTY)
                .title("队伍 · " + leaderName)
                .size(280, 170);

        window.addLabel("joined", 20, 18, "你已加入 " + leaderName + " 的队伍")
                .color("#FFD166")
                .scale(1.1f);

        window.addLabel("hint", 20, 44, "点击下方按钮开始，或关闭窗口离开")
                .color("#B9A7D6");

        window.addButton("start", 20, 112, 240, 28, "开始游戏")
                .backgroundColor("#FF2E9E5B")
                .hoverColor("#FF3FB56C")
                .textColor("#FFFFFFFF")
                .radius(8)
                .onClick(event -> {
                    Player p = event.player();
                    api.playSound(p, soundId("click"), 0.8f, 1.0f);
                    api.closeWindow(p, WINDOW_PARTY);
                    p.sendMessage("§a队伍开始游戏（示例）");
                })
                .widthPercent(86)
                .xPercent(7);

        api.openWindow(player, window);
    }
}
```

### 要点

- `ClickEvent.runCommand` 只是“帮玩家输入一条命令”，真正的邀请校验必须在命令处理里再做一次，不能信任参数。
- 邀请发出前就检查 `isClientSupported`，避免对方点同意后才发现打不开界面。
- 聊天按钮适合“邀请、确认、跳转”，不适合承载复杂交互；真正的交互放进 GUI。
- 命令名、窗口 id 都要加前缀，避免和其他插件冲突。

## 9.2 案例二：带遮罩的确认弹窗

### 场景

玩家在牌局界面点“离开”或按 Esc，弹出一个压暗整屏的确认框；底层牌桌保持打开，但点不到。

### 用到的 API

| API | 用途 |
| --- | --- |
| `fullscreen(true)` + `titleBar(false)` | 全屏遮罩，挡住底层点击 |
| `alwaysOnTop(true)` | 底层界面刷新时不会把弹窗盖住 |
| `dim(150)` | 整屏压暗 |
| `closeOnEsc(false)` + `onEscape` | Esc 不直接关，转成服务端事件 |
| `closeWindow(player, 具体id)` | 只关弹窗，不关底层 |

### 代码

```java
import com.guiapi.paper.GuiWindow;
import org.bukkit.entity.Player;

public final class ConfirmDialogDemo extends DemoPluginBase {

    private static final String ID_BOARD = "demo_board";
    private static final String ID_CONFIRM = "demo_board_confirm";

    /** 底层牌桌：Esc 也先弹确认框。 */
    void openBoard(Player player) {
        GuiWindow board = new GuiWindow(ID_BOARD)
                .fullscreen(true)
                .titleBar(false)
                .backgroundColor("#00000000")
                .borderWidth(0)
                .closeOnEsc(false)
                .onEscape(event -> confirmQuit(event.player()));

        board.addImage("bg", 0, 0, 0, 0, imageId("table"))
                .fit("cover")
                .widthPercent(100)
                .heightPercent(100);

        board.addPanel("bottomBar", 0, 0, 0, 0)
                .borderWidth(0)
                .backgroundColor("#C4080D12")
                .widthPercent(100)
                .heightPercent(22)
                .yPercent(78);

        board.addLabel("title", 0, 0, "牌桌").color("#FFD166").scale(1.8f)
                .xPercent(3).yPercent(2);

        board.addButton("leave", 0, 0, 0, 28, "离开牌局")
                .backgroundColor("#FF8E3B3B")
                .hoverColor("#FFA84A4A")
                .textColor("#FFFFFFFF")
                .radius(8)
                .onClick(event -> confirmQuit(event.player()))
                .widthPercent(14)
                .xPercent(83)
                .yPercent(82);

        api.openWindow(player, board);
    }

    /** 确认弹窗：全屏透明 + dim + alwaysOnTop，底层牌桌不关。 */
    private void confirmQuit(Player player) {
        GuiWindow confirm = new GuiWindow(ID_CONFIRM)
                .fullscreen(true)
                .titleBar(false)
                .backgroundColor("#00000000")
                .borderWidth(0)
                .alwaysOnTop(true)
                .dim(150)
                .closeOnEsc(false)
                .onEscape(event -> api.closeWindow(event.player(), ID_CONFIRM));

        confirm.addPanel("card", 0, 0, 0, 0)
                .borderWidth(0)
                .backgroundColor("#F018181C")
                .radius(10)
                .widthPercent(34)
                .heightPercent(26)
                .xPercent(33)
                .yPercent(30);

        confirm.addLabel("title", 0, 0, "确定要离开牌局吗？")
                .color("#FFFFFFFF")
                .scale(1.4f)
                .centered(true)
                .widthPercent(34)
                .xPercent(33)
                .yPercent(35);

        confirm.addLabel("hint", 0, 0, "离开后你的座位会被电脑接管")
                .color("#B9A7D6")
                .centered(true)
                .widthPercent(34)
                .xPercent(33)
                .yPercent(43);

        confirm.addButton("stay", 0, 0, 0, 26, "继续游戏")
                .backgroundColor("#FF2E9E5B")
                .hoverColor("#FF3FB56C")
                .textColor("#FFFFFFFF")
                .radius(8)
                .onClick(event -> api.closeWindow(event.player(), ID_CONFIRM))
                .widthPercent(14)
                .xPercent(35)
                .yPercent(49);

        confirm.addButton("quit", 0, 0, 0, 26, "确定离开")
                .backgroundColor("#FF8E3B3B")
                .hoverColor("#FFA84A4A")
                .textColor("#FFFFFFFF")
                .radius(8)
                .onClick(event -> {
                    Player p = event.player();
                    api.closeWindow(p, ID_CONFIRM);
                    api.closeWindow(p, ID_BOARD);
                    api.stopSound(p, soundId("bgm"));
                    p.sendMessage("§7你已离开牌局");
                })
                .widthPercent(14)
                .xPercent(51)
                .yPercent(49);

        api.openWindow(player, confirm);
    }
}
```

### 要点

- 模态框必须 `fullscreen(true)`：窗口背景会消费整个窗口矩形内的点击，不全屏就挡不住底层。
- **`dim` 本身不挡点击**，它只是画一层暗色；挡点击靠全屏窗口。
- `alwaysOnTop(true)` 保证底层牌桌因为状态变化重新 `openWindow` 时不会盖住弹窗。
- `closeOnEsc(false)` 后 Esc 和标题栏 × 都会变成 `"esc"` 事件；必须注册 `onEscape`，否则窗口关不掉。这里按 Esc 关的是弹窗本身。
- 关闭用具体 id；`closeWindow(player, null)` 会把底层牌桌一起关掉。
- 两个窗口同时有 dim 时客户端只取最大值，不会叠加变黑。

## 9.3 案例三：手牌横向拖动列表

### 场景

一手 7~10 张卡牌，屏幕宽度放不下。玩家可以左右拖动整排手牌；轻点选中 / 取消选中，拖动不会误触选中。

### 用到的 API

| API | 用途 |
| --- | --- |
| `dragGroup("hand")` | 整组横向拖动 |
| `aspect(160.0 / 225.0)` | 卡牌等比 |
| 透明 `Panel` 点击层 | 先添加，优先接管点击 |
| `widthPercent` / `yPercent` | 自适应布局 |
| `openWindow` 重绘 | 选中状态变化后刷新高亮 |

### 代码

```java
import com.guiapi.paper.GuiWindow;
import org.bukkit.entity.Player;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.UUID;

public final class HandStripDemo extends DemoPluginBase {

    private static final String ID_HAND = "demo_hand";

    private static final double CARD_W = 12.0;          // 卡牌宽度百分比
    private static final double GAP = 1.2;              // 卡牌间距百分比
    private static final double CARD_ASPECT = 160.0 / 225.0;
    private static final double HAND_Y = 60.0;          // 手牌区顶部 y 百分比（卡牌高度约 25%，底部留到 85%）
    private static final double SELECT_LIFT = 2.0;      // 选中上浮的百分比

    /** 每个玩家当前手牌与选中项，重绘时从这里恢复状态。 */
    private final Map<UUID, List<String>> hands = new HashMap<>();
    private final Map<UUID, Integer> selected = new HashMap<>();

    void open(Player player, List<String> hand) {
        hands.put(player.getUniqueId(), new ArrayList<>(hand));
        render(player);
    }

    private void render(Player player) {
        List<String> hand = hands.getOrDefault(player.getUniqueId(), List.of());
        Integer picked = selected.get(player.getUniqueId());

        // 整排总宽；超过可用宽度才允许拖动
        double totalW = hand.size() * CARD_W + Math.max(0, hand.size() - 1) * GAP;
        boolean canDrag = totalW > 92;
        double startX = canDrag ? 3.0 : (100.0 - totalW) / 2.0;

        GuiWindow window = new GuiWindow(ID_HAND)
                .fullscreen(true)
                .titleBar(false)
                .backgroundColor("#00000000")
                .borderWidth(0);

        window.addImage("bg", 0, 0, 0, 0, imageId("table"))
                .fit("cover")
                .widthPercent(100)
                .heightPercent(100);

        window.addLabel("title", 0, 0, "你的手牌（左右拖动）")
                .color("#FFD166")
                .scale(1.3f)
                .xPercent(3)
                .yPercent(2);

        for (int i = 0; i < hand.size(); i++) {
            final int index = i;
            String card = hand.get(i);
            double x = startX + i * (CARD_W + GAP);
            double y = (picked != null && picked == i) ? HAND_Y - SELECT_LIFT : HAND_Y;

            // 1) 透明点击层：先添加，点击优先命中它
            var hit = window.addPanel("hit" + i, 0, 0, 0, 0);
            hit.borderWidth(0)
                    .backgroundColor("#00000000")
                    .radius(0)
                    .onClick(event -> toggle(player, index))
                    .tooltip("#FFD166|" + cardName(card));
            if (canDrag) hit.dragGroup("hand");
            hit.widthPercent(CARD_W)
                    .aspect(CARD_ASPECT)
                    .xPercent(x)
                    .yPercent(y);

            // 2) 卡面：视觉在点击层之上，不接管点击；和点击层加入同一个拖动组才会一起移动
            var img = window.addImage("card" + i, 0, 0, 0, 0, imageId("card_" + card));
            img.fit("contain");
            if (canDrag) img.dragGroup("hand");
            img.widthPercent(CARD_W)
                    .aspect(CARD_ASPECT)
                    .xPercent(x)
                    .yPercent(y);
            img.hoverLift(true);
        }

        window.addButton("play", 0, 0, 0, 26, "打出选中牌")
                .backgroundColor("#FF2E9E5B")
                .hoverColor("#FF3FB56C")
                .textColor("#FFFFFFFF")
                .radius(8)
                .onClick(event -> {
                    Player p = event.player();
                    Integer choice = selected.get(p.getUniqueId());
                    List<String> current = hands.getOrDefault(p.getUniqueId(), List.of());
                    if (choice == null || choice < 0 || choice >= current.size()) {
                        p.sendMessage("§c先点一张牌");
                        return;
                    }
                    api.playSound(p, soundId("click"), 0.8f, 1.0f);
                    p.sendMessage("§a打出: " + cardName(current.get(choice)));
                })
                .widthPercent(16)
                .xPercent(42)
                .yPercent(88);

        api.openWindow(player, window);
    }

    private void toggle(Player player, int index) {
        List<String> hand = hands.getOrDefault(player.getUniqueId(), List.of());
        if (index < 0 || index >= hand.size()) return;

        Integer current = selected.get(player.getUniqueId());
        if (current != null && current == index) selected.remove(player.getUniqueId());
        else selected.put(player.getUniqueId(), index);

        render(player); // 状态存在服务端，重绘时重新写入
    }

    private static String cardName(String card) {
        return switch (card) {
            case "skip" -> "跳过";
            case "bomb" -> "炸弹";
            default -> card;
        };
    }
}
```

### 要点

- 点击层必须**先添加**：客户端对同一窗口内的控件按声明顺序做命中检测，先声明的可点击控件先拿到点击；绘制则相反，后添加的画在上层。
- 点击层和卡面都要挂**同一个** `dragGroup`：分组只让挂了组的控件一起平移；只给点击层挂组，拖动时卡面会原地不动。
- `dragGroup` 只在整组总宽超过窗口时可拖；能放下时拖动完全无效。`canDrag` 只是提前决定要不要挂组，挂上也不会动。
- 拖动超过约 3px 算拖动，松手不触发点击；所以轻点选中、拖动翻牌不会互相干扰。
- 选中状态保存在服务端 `selected`，重绘时通过 `y` 百分比上浮体现；客户端的勾选状态不会自动保留。
- 拖动组内的位置变化不做补间，手牌不会拖泥带水；`anim` 对手牌组无效。
- 卡牌 id 用 `card0`、`hit0`，不要两张牌共用一个 id。

## 9.4 案例四：全屏特效层 + 分帧动画

### 场景

摸到炸弹 / 爆炸时，在所有还在牌局里的玩家屏幕上叠一层特效：橙黄爆炸星、漫画字、Boom! 左右倾斜交替，持续 24 tick 后自动消失。底层牌桌保持打开。

### 用到的 API

| API | 用途 |
| --- | --- |
| `fullscreen(true)` + 透明背景 | 特效层，不遮住牌桌 |
| `alwaysOnTop(true)` | 特效永远在牌桌之上 |
| 预生成的 `boom_l` / `boom_r` | **没有旋转能力**，用两张倾斜图交替模拟旋转 |
| `BukkitScheduler` 每 3 tick 一帧 | 分帧动画 |
| 自写 `heightPct(widthPct, aspect)` | 宽度百分比换算成高度百分比（公式见 [08](08-布局技巧与常见问题.md) 8.1.4） |
| `closeWindow(具体id)` | 只关特效层 |

### 代码

```java
import com.guiapi.paper.GuiWindow;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;

import java.util.List;

public final class EffectFramesDemo extends DemoPluginBase {

    private static final String ID_FX = "demo_fx";

    /** 在所有观众屏幕上播放 8 帧爆炸，24 tick 后收尾。 */
    void playExplosion(List<Player> viewers, double centerX, double centerY) {
        for (int frame = 0; frame < 8; frame++) {
            final int f = frame;
            Bukkit.getScheduler().runTaskLater(this, () -> {
                for (Player viewer : viewers) {
                    if (viewer.isOnline()) showFrame(viewer, centerX, centerY, f);
                }
            }, 3L * frame);
        }

        Bukkit.getScheduler().runTaskLater(this, () -> {
            for (Player viewer : viewers) {
                if (viewer.isOnline()) api.closeWindow(viewer, ID_FX);
            }
        }, 24L);
    }

    private void showFrame(Player viewer, double centerX, double centerY, int frame) {
        boolean tiltRight = frame % 2 == 1;
        double wobbleX = frame == 0 ? 0 : (tiltRight ? 0.45 : -0.45);
        double wobbleY = frame == 0 ? 0 : (frame % 4 == 1 ? -0.3 : 0.3);

        double wordW = 12.0;
        double wordH = heightPct(wordW, 420.0 / 220.0);

        GuiWindow layer = new GuiWindow(ID_FX)
                .fullscreen(true)
                .titleBar(false)
                .backgroundColor("#00000000")
                .borderWidth(0)
                .alwaysOnTop(true)
                .closeOnEsc(false)
                .onEscape(event -> api.closeWindow(event.player(), ID_FX));

        layer.addImage("word", 0, 0, 0, 0, imageId(tiltRight ? "boom_r" : "boom_l"))
                .fit("contain")
                .widthPercent(wordW)
                .aspect(420.0 / 220.0)
                .xPercent(centerX - wordW / 2 + wobbleX)
                .yPercent(centerY - wordH / 2 + wobbleY);

        api.openWindow(viewer, layer);
    }

    /** 按 640×430 设计基准估算高度百分比；画布更大时请改用 aspect() 保证严格等比。 */
    private static double heightPct(double widthPct, double aspect) {
        return widthPct / 100.0 * 640.0 / aspect / 430.0 * 100.0;
    }
}
```

### 要点

- **没有旋转 API**：不要让美术只给一张正向图，必须预先生成左倾 / 右倾两版（或多版）素材，按帧切换；这是本项目模拟旋转的唯一做法。
- 每帧都 `openWindow` 同一个 id：客户端按同一 id 替换内容，不会叠出多个特效窗口；被玩家拖动过的位置也会保留。
- 想减少流量，首帧 `openWindow`，后续帧改用 `updateWidget` 改 `image`、`xPct`、`yPct`；但多图逐帧切换时，整窗重绘更好维护，且新图要先 `preloadImage` 才会下发。
- 帧间隔 3 tick（约 6.7 帧/秒）足够表现“爆炸 + 抖动”，再密会明显增加包量。
- 特效层是独立窗口 id，结束时只关它；**不要 `closeWindow(player, null)`**，那会把牌桌也关掉。
- 关闭时机要检查业务状态：如果玩家此刻正在拆弹 / 选牌，不要用定时器把必须操作的弹层一起关掉。
- `alwaysOnTop(true)` 保证牌桌刷新时不会盖住特效。

## 9.5 案例五：语音 / 状态指示与 BGM 闪避

### 场景

牌桌上有一行“你当前在语音发言”。状态变化才刷新，不整窗重绘；有人说话时把 BGM 音量实时压到 0，说完恢复，音乐不从头重播。

### 用到的 API

| API | 用途 |
| --- | --- |
| `api.windowsOf(player)` | 窗口没开时跳过刷新 |
| `updateWidget(..., Map.of("visible", ..., "color", ...))` | 只改一个 Label，保留输入焦点 / 拖窗位置 |
| `playLoopingSound` | 开局播放 BGM |
| `setLoopingSoundVolume` | 实时压低 / 恢复，不重启 |
| `stopSound` | 离开 / 退出时收尾 |

### 代码

```java
import com.guiapi.paper.GuiWindow;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerQuitEvent;

import java.util.HashMap;
import java.util.Map;
import java.util.UUID;

public final class VoiceStatusDemo extends DemoPluginBase implements Listener {

    private static final String ID_TABLE = "demo_table";
    private static final float BGM_VOLUME = 0.55f;
    private static final float BGM_MUTED = 0.0f;

    /** 上一次的发言状态 / BGM 闪避状态，用来做状态差分，避免无意义刷新。 */
    private final Map<UUID, Boolean> lastTalking = new HashMap<>();
    private final Map<UUID, Boolean> ducked = new HashMap<>();

    @Override
    public void onEnable() {
        super.onEnable();
        getServer().getPluginManager().registerEvents(this, this);
        // 每 5 tick 采样一次语音状态；20 tick = 1 秒，5 tick = 250ms
        getServer().getScheduler().runTaskTimer(this, this::tickVoice, 20L, 5L);
    }

    void openTable(Player player) {
        GuiWindow table = new GuiWindow(ID_TABLE)
                .fullscreen(true)
                .titleBar(false)
                .backgroundColor("#00000000")
                .borderWidth(0)
                .closeOnEsc(false)
                .onEscape(event -> {
                    // 关闭窗口不会自动停 BGM，这里手动收尾
                    api.closeWindow(event.player(), ID_TABLE);
                    api.stopSound(event.player(), soundId("bgm"));
                });

        table.addImage("bg", 0, 0, 0, 0, imageId("table"))
                .fit("cover")
                .widthPercent(100)
                .heightPercent(100);

        table.addLabel("talking", 0, 0, "你当前在语音发言")
                .color("#FF5BE39A")
                .centered(true)
                .widthPercent(40)
                .xPercent(30)
                .yPercent(62)
                .visible(false);

        api.openWindow(player, table);

        // BGM 与窗口生命周期无关：这里显式开始，离开时显式停止
        api.playLoopingSound(player, soundId("bgm"), BGM_VOLUME);
        lastTalking.put(player.getUniqueId(), false);
        ducked.put(player.getUniqueId(), false);
    }

    private void tickVoice() {
        boolean anyoneTalking = false;
        for (Player online : Bukkit.getOnlinePlayers()) {
            if (isTalking(online)) {
                anyoneTalking = true;
                break;
            }
        }

        for (Player player : Bukkit.getOnlinePlayers()) {
            boolean now = isTalking(player);

            // 状态没变就什么都不发
            Boolean previous = lastTalking.put(player.getUniqueId(), now);
            boolean changed = previous == null || previous != now;

            if (changed && api.windowsOf(player).containsKey(ID_TABLE)) {
                api.updateWidget(player, ID_TABLE, "talking", Map.of(
                        "visible", now,
                        "color", now ? 0xFF5BE39A : 0xFF8C9AAE));
            }

            boolean shouldDuck = anyoneTalking && api.windowsOf(player).containsKey(ID_TABLE);
            Boolean wasDucked = ducked.put(player.getUniqueId(), shouldDuck);
            if (wasDucked == null || wasDucked != shouldDuck) {
                api.setLoopingSoundVolume(player, soundId("bgm"),
                        shouldDuck ? BGM_MUTED : BGM_VOLUME);
            }
        }
    }

    /** 真实项目里由 Simple Voice Chat 桥接提供；这里留空以便单独编译运行。 */
    private boolean isTalking(Player player) {
        return false;
    }

    @EventHandler
    public void onQuit(PlayerQuitEvent event) {
        Player player = event.getPlayer();
        api.stopSound(player, soundId("bgm"));
        lastTalking.remove(player.getUniqueId());
        ducked.remove(player.getUniqueId());
    }
}
```

### 要点

- **只在状态变化时刷新**：`lastTalking` / `ducked` 做差分，避免每 5 tick 给所有人发一遍相同数据。
- 只改一个 Label 用 `updateWidget`，不重绘整窗：玩家拖过的窗口位置、输入框内容都不会丢。
- 刷新前先用 `windowsOf` 判断窗口是否还开着；已关闭时客户端会忽略 `updateWidget`。
- `setLoopingSoundVolume(0)` 不会停掉 BGM，只是静音；恢复时从原位置继续，不从头播。
- BGM 要显式 `playLoopingSound`，因为打开窗口不会自动放音乐；也要显式 `stopSound`，因为关闭窗口不会自动停音乐。
- 需要实时音量时，客户端最低版本要求 `1.3.13`；低于这个版本的客户端会忽略音量更新，策略上要么拒绝加入，要么接受“不闪避”。
- `Map.of` 里的颜色是 **int ARGB**；写成 `"#5BE39A"` 字符串不会生效。

## 9.6 案例与 API 对照

| 案例 | 核心 API | 容易踩的坑 |
| --- | --- | --- |
| 聊天邀请 | `Component` + `ClickEvent.runCommand`、`isClientSupported`、`openWindow` | 命令参数未校验；对方没装模组 |
| 确认弹窗 | `fullscreen`、`alwaysOnTop`、`dim`、`closeOnEsc(false)`、`onEscape` | 用 `closeWindow(player, null)` 把底层一起关掉；没有 `onEscape` 导致 Esc 关不掉 |
| 手牌拖动 | `dragGroup`、`aspect`、透明点击层、`updateWidget` / 重绘 | 点击层后添加导致点不到；id 重复；拖动组能放下时以为能拖 |
| 全屏特效 | 全屏透明窗口、`alwaysOnTop`、预生成多帧图、调度器 | 以为有旋转 API；特效结束时关掉所有窗口；定时器把必须操作的弹层一起关掉 |
| 状态刷新 | `updateWidget`、`windowsOf`、`playLoopingSound`、`setLoopingSoundVolume` | 每 tick 整窗重绘；把颜色写成十六进制字符串；关闭窗口后 BGM 还在放 |
