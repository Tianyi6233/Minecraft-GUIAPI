# GuiApi 可改键快捷键（服务端下发）

适用版本：GuiApi **服务端 1.8.0+**、**客户端 1.7.1+**。全程由服务端插件调用，客户端模组无需写任何代码。

## 1. 两种快捷键

| 方式 | 谁注册 | 玩家能否改键 | 出现在按键设置 | 典型用途 |
| --- | --- | --- | --- | --- |
| `GuiApi.bindKey(...)` | 服务端插件 | 否 | 否 | 插件自己的快捷入口，服务端随时下发/回收 |
| `GuiApi.registerKey(...)` | 服务端插件 | 是 | 是 | 需要让玩家在「选项 → 控制 → 按键绑定」里自行改键的功能 |

两者可以同时使用，互不影响，回调都走 `addKeyHandler(keyId, handler)`。本文只介绍第二种。

## 2. 方法签名

```java
void registerKey(Player player, String keyId, String label, Integer defaultKeyCode);
void unregisterKey(Player player, String keyId);
```

| 参数 | 说明 |
| --- | --- |
| `player` | 目标玩家 |
| `keyId` | 逻辑 id，建议加插件前缀（如 `mymod:shop`）。同一玩家重复注册同一 id 会直接复用，不会创建第二个按键 |
| `label` | 显示在按键设置里的名称，直接作为文本使用 |
| `defaultKeyCode` | 默认 **GLFW 键码**；传 `null` 或 `<= 0` 表示默认不绑定，玩家自行指定 |

## 3. 服务端示例

```java
import com.guiapi.paper.GuiApi;
import org.bukkit.entity.Player;

public final class ShopKeys {

    private static final String KEY_SHOP = "mymod:shop";
    private static final String KEY_MAIL = "mymod:mail";
    // GLFW_KEY_P = 80。服务端不要 import LWJGL。
    private static final int KEY_P = 80;

    private final GuiApi api = GuiApi.get();

    public void onJoin(Player player) {
        // 默认 P 键打开商城；玩家可在按键设置里改成别的
        api.registerKey(player, KEY_SHOP, "打开商城", KEY_P);

        // 不设默认键；玩家自己去按键设置里绑
        api.registerKey(player, KEY_MAIL, "打开邮箱", null);
    }

    public void registerHandlers() {
        // 回调和 bindKey 完全一样，只认 keyId
        api.addKeyHandler(KEY_SHOP, player -> api.openWindow(player, shopWindow(player)));
        api.addKeyHandler(KEY_MAIL, player -> api.openWindow(player, mailWindow(player)));
    }

    public void onQuit(Player player) {
        // 可选：玩家退出时从按键设置移除。不调也会在客户端断开时自动清理。
        api.unregisterKey(player, KEY_SHOP);
        api.unregisterKey(player, KEY_MAIL);
    }
}
```

## 4. 工作原理

1. 服务端调用 `registerKey`，通过 `register_key` 消息把 `keyId`、`label`、`defaultKeyCode` 发给客户端。
2. 客户端动态创建一个原版 `KeyMapping`，注册到「选项 → 控制 → 按键绑定 → GuiApi」分类。
3. 玩家在按键设置里改键 → 原版自动写入 `options.txt` → 重启、重连后保留。
4. 客户端每帧轮询 `consumeClick()`，按下时把 `keyId` 发回服务端 → 触发 `addKeyHandler` 注册的回调。
5. 服务端只认 `keyId`，玩家改成什么物理键都不影响。
6. 玩家断开连接时，客户端自动把这些键从按键设置移除，避免残留到其他服务器。

## 5. 注意事项

- **GLFW 键码**：`A`=65、`P`=80、`K`=75、空格=32。服务端不要 `import org.lwjgl.glfw.GLFW`，直接写整数。
- **任意界面打开时不触发**：聊天框、背包、暂停菜单、GuiApi 窗口都算。想"按键关闭窗口"做不到，请用窗口里的按钮或 Esc。
- **持久化**：设置写在客户端 `options.txt`，属于玩家个人设置，跨服务器保留（只要 keyId 不冲突）。
- **重连幂等**：服务端每次握手会重发注册，客户端已存在的 id 不会重复创建。
- **keyId 冲突**：不同插件用了相同 keyId 会互相覆盖，务必加插件前缀。
- **分类**：所有 `registerKey` 注册的键都显示在 `GuiApi` 分类下。
- **默认未绑定**：`defaultKeyCode` 传 `null` 时，按键设置里显示为"未绑定"，玩家需要手动设置后才能使用。
