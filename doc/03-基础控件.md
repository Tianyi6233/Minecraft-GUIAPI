# 03 · 基础控件

本章只使用 `gui-api-paper` 插件 jar 暴露的公开 API，不需要也不依赖源码。所有控件都通过 `GuiWindow` 的 `addXxx(...)` 工厂方法创建并立即加入窗口，随后可以链式配置。

> 示例默认已导入：`com.guiapi.paper.GuiApi`、`com.guiapi.paper.GuiWindow`、`com.guiapi.paper.widget.*`、`org.bukkit.entity.Player`。坐标、百分比、负坐标等布局规则详见 [02-窗口与坐标](02-窗口与坐标.md)。

## 3.1 Widget 基类

### 用途

`Widget` 是所有控件的抽象基类，负责 id、坐标、尺寸、可见性、悬停提示、发光、动画和拖动组等通用能力。它本身不能实例化，通过 `GuiWindow.addXxx(...)` 或 `window.add(new Panel(...))` 得到具体控件。

控件坐标相对**窗口内容区**（标题栏下方），单位为像素；设计基准是 640×430 的虚拟画布。

### 通用能力

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `String id()` | 控件 id | — | 同一窗口内唯一，事件与 `updateWidget` 都用它定位 |
| `int x() / int y()` | 当前左上角坐标 | — | 只读；构造时传入 |
| `int width() / int height()` | 当前宽高 | — | 只读；部分控件高度由构造决定 |
| `String tooltip()` | 当前悬停提示 | — | 只读 |
| `Widget position(int x, int y)` | 移动控件 | `x`、`y`：内容区坐标 | 返回 `Widget`，调用后不能再链子类专属方法 |
| `Widget size(int width, int height)` | 修改宽高 | `width`、`height`：像素 | 返回 `Widget` |
| `Widget tooltip(String tooltip)` | 悬停提示 | 文本 | 支持 `\n` 换行；某行以 `#RRGGBB\|` 开头可单独指定该行颜色（如 `"#FF5555\|危险"`） |
| `Widget visible(boolean visible)` | 显示 / 隐藏 | `true` 显示 | 默认显示；隐藏后既不绘制也不接收点击，可用 `updateWidget(..., Map.of("visible", true))` 再显示 |
| `Widget xPercent(double percent)` | 横向百分比布局 | 百分比，`50` = 一半窗口宽 | 最终 x = `percent * 窗口宽 / 100 + x`，`x` 仍作为偏移叠加 |
| `Widget yPercent(double percent)` | 纵向百分比布局 | 百分比 | 最终 y = `percent * 内容区高 / 100 + y` |
| `Widget widthPercent(double percent)` | 宽度百分比 | 百分比 | 最终宽 = `percent * 窗口宽 / 100 + width` |
| `Widget heightPercent(double percent)` | 高度百分比 | 百分比 | 最终高 = `percent * 内容区高 / 100 + height`；存在 `aspect` 时被 `aspect` 覆盖 |
| `Widget aspect(double widthOverHeight)` | 固定宽高比 | 宽 ÷ 高（如卡牌 `160.0 / 225.0`） | 高度由当前宽度推导；必须传 `> 0`，否则忽略 |
| `Widget dragGroup(String group)` | 加入横向拖动组 | 组名，同组控件一起移动 | 仅当整组宽度超出窗口时可拖动；空白组名等于取消分组 |
| `Widget glow(String hex)` | 高亮描边 | `"#RRGGBB"` 或 `"#AARRGGBB"` | 纯视觉，不改变点击区域；不传 alpha 时按不透明处理 |
| `Widget hoverLift(boolean lift)` | 悬停上抬 | `true` 上抬约 3 像素 | 纯视觉，点击判定仍在原位置 |
| `Widget anim(int ms)` | 位置补间 | 时长（毫秒），缓动默认 `out` | 等价于 `anim(ms, "out")` |
| `Widget anim(int ms, String ease)` | 位置补间 | `ms` 时长；`ease` 取 `linear`、`in`、`out`、`inOut` | `ms <= 0` 表示恢复默认平滑跟随（不是瞬移）；改坐标或 `updateWidget` 改坐标时生效 |

默认值：`visible` 未设置时视为 `true`；`tooltip` 为 `null`；`glow`、`hoverLift`、`dragGroup`、`anim` 未设置时分别不发光、不上抬、不分组、使用客户端默认平滑跟随。

### 链式调用陷阱（重点）

基类方法 `position / size / visible / xPercent / yPercent / widthPercent / heightPercent / aspect / dragGroup / glow / hoverLift / anim / tooltip` 的返回类型都是 **`Widget`**。因此：

- 先调用子类专属方法（`Button.onClick`、`Label.color`、`Panel.radius`、`ImageWidget.fit`、`TextField.live`、`Slider.min`、`Checkbox.onToggle`、`Dropdown.onSelect`、`ItemWidget.amount` 等），再调用基类方法，链的最后可以停在基类；
- 不要反过来：先调基类方法会拿到 `Widget`，后面就调不到子类方法。

```java
GuiWindow window = new GuiWindow("shop").size(300, 200);

// 正确：子类方法在前，基类方法收尾
window.addImage("logo", 170, 20, 100, 60, "shop_logo")
        .fit("contain")          // ImageWidget
        .hoverLift(true)         // Widget
        .tooltip("商店 Logo");    // Widget

// 错误：widthPercent 返回 Widget，后面没有 fit(...)，无法编译
// window.addImage("logo", 170, 20, 100, 60, "shop_logo")
//         .widthPercent(30)
//         .fit("contain");
```

同样，若要在拿到子类引用后继续设置基类属性，请把子类方法全部放在前面，或拆成多行重新引用局部变量：

```java
GuiWindow window = new GuiWindow("shop").size(300, 200);
Button ok = window.addButton("btn_ok", 10, 10, 80, 20, "确定")
        .radius(4)
        .onClick(e -> e.player().sendMessage("ok"));
ok.widthPercent(30).xPercent(60);   // 之后再用基类方法，不再需要子类类型
```

## 3.2 Panel

### 用途

矩形底板：卡片背景、标题条、侧边栏、遮罩、点击热区。支持纯色 / 渐变色、边框、圆角、悬停变色和整块点击。

### 构造 / 工厂方法

```java
Panel addPanel(String id, int x, int y, int width, int height)
```

| 参数 | 说明 |
| --- | --- |
| `id` | 控件 id |
| `x, y` | 相对内容区左上角；负值表示从内容区中心偏移 |
| `width, height` | 像素尺寸；负宽/负高表示贴右/下边缘并保留该边距 |

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Panel backgroundColor(String hex)` | 背景色 | `"#RRGGBB"` / `"#AARRGGBB"` | `"#00000000"` 完全透明 |
| `Panel backgroundColor(int argb)` | 背景色 | ARGB 整数 | 推荐用于动态颜色 |
| `Panel borderColor(String hex)` | 边框色 | 同上 | 默认 `0xFF000000` |
| `Panel borderColor(int argb)` | 边框色 | ARGB 整数 | — |
| `Panel borderWidth(int width)` | 边框粗细 | 像素，默认 `1` | `0` 表示无边框 |
| `Panel radius(int radius)` | 圆角 | 像素，默认 `0` | 负数按 0 处理；只是视觉，布局仍是矩形 |
| `Panel hoverColor(String hex)` | 悬停背景色 | 同上 | 不设置则悬停不变色 |
| `Panel hoverColor(int argb)` | 悬停背景色 | ARGB 整数 | — |
| `Panel gradient(String topHex, String bottomHex)` | 纵向渐变 | 顶部色、底部色 | 仅 `radius == 0` 时生效，且会覆盖 `backgroundColor` |
| `Panel onClick(Consumer<GuiActionEvent> handler)` | 整块点击回调 | 回调 | 设置后客户端把整块面板标记为可点击 |

只读方法：`clickHandler()`。

默认值：背景 `0x00000000`（透明）、边框 `0xFF000000`、边框宽 `1`、圆角 `0`、无悬停色、无点击回调。`default` 风格下透明背景不填充；`minecraft` 风格下透明背景回退为原版面板灰。

### 示例

```java
void openMenu(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("menu").title("菜单").size(300, 200);

    window.addPanel("card", 20, 20, 120, 60)
            .backgroundColor("#FF232936")
            .borderColor("#FF3A4356")
            .borderWidth(1)
            .radius(8)
            .hoverColor("#FF313A4C")
            .onClick(e -> e.player().sendMessage("你点击了卡片"));

    window.addPanel("header", 0, 0, 0, 24)
            .gradient("#FF2D2F38", "#FF18181C")
            .borderWidth(0)
            .widthPercent(100);

    window.addButton("close", 20, 150, 100, 20, "关闭")
            .radius(4)
            .onClick(e -> api.closeWindow(e.player(), "menu"));

    api.openWindow(player, window);
}
```

### 事件回调

| action | value | 触发时机 |
| --- | --- | --- |
| `click` | 无（`valueAsString()` 为 `""`） | 点击整块面板；仅当调用了 `onClick(...)` |

## 3.3 Label

### 用途

静态文字。适合标题、说明、数值展示。内容变化可通过 `updateWidget(..., Map.of("text", ...))` 实时刷新。

### 构造 / 工厂方法

```java
Label addLabel(String id, int x, int y, String text)
```

构造时宽 `0`、高 `9`。宽度为 0 时不换行；设置正宽度后会自动按宽度折行。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Label text(String text)` | 文本 | 任意字符串 | 支持 `\n` 手动换行 |
| `Label color(String hex)` | 文字颜色 | `"#RRGGBB"` / `"#AARRGGBB"` | 默认 `0xFFFFFFFF`（白） |
| `Label color(int argb)` | 文字颜色 | ARGB 整数 | — |
| `Label centered(boolean centered)` | 居中 | `true` 居中 | 默认 `false`；有正宽度时在自身盒内居中，宽度为 0 时相对整窗居中 |
| `Label scale(float scale)` | 字号缩放 | 倍数，默认 `1.0` | 会影响自动折行宽度，行高也随缩放增大 |

只读方法：`text()`、`color()`、`centered()`、`scale()`。

`Label` 没有点击回调；需要点击请用 `Panel` 或 `Button`。

### 示例

```java
void openTitle(Player player) {
    GuiWindow window = new GuiWindow("title_demo").title("标题示例").size(320, 160);

    window.addLabel("title", 0, 12, "每日商店")
            .color("#FFD166")
            .scale(1.6f)
            .centered(true)
            .widthPercent(100);

    window.addLabel("desc", 20, 44, "每天 0 点刷新商品，售完即止。")
            .color("#C8D2E0")
            .widthPercent(80);

    GuiApi.get().openWindow(player, window);
}
```

### 事件回调

无。`Label` 不接收点击。

## 3.4 Button

### 用途

可点击按钮，是最常用的事件入口。

### 构造 / 工厂方法

```java
Button addButton(String id, int x, int y, int width, int height, String text)
```

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Button text(String text)` | 按钮文字 | 文本 | 无 `\n` 换行，单行居中 |
| `Button backgroundColor(String hex)` | 背景色 | `"#RRGGBB"` / `"#AARRGGBB"` | 不设置则用主题默认色 |
| `Button backgroundColor(int argb)` | 背景色 | ARGB 整数 | — |
| `Button hoverColor(String hex)` | 悬停背景色 | 同上 | 不设置则用主题悬停色 |
| `Button hoverColor(int argb)` | 悬停背景色 | ARGB 整数 | — |
| `Button textColor(String hex)` | 文字颜色 | 同上 | 默认白色 |
| `Button textColor(int argb)` | 文字颜色 | ARGB 整数 | — |
| `Button radius(int radius)` | 圆角 | 像素，默认 `0` | 负数按 0 处理 |
| `Button onClick(Consumer<GuiActionEvent> handler)` | 点击回调 | 回调 | 整个按钮矩形都可点击 |

只读方法：`text()`、`clickHandler()`。

### 示例

```java
void openConfirm(Player player, Runnable onConfirm) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("confirm")
            .title("确认")
            .size(260, 140);

    window.addLabel("msg", 20, 20, "确定要执行吗？")
            .color("#E8EFF7")
            .widthPercent(80);

    window.addButton("btn_ok", 20, 80, 100, 22, "确定")
            .backgroundColor("#FF3B8E5A")
            .hoverColor("#FF4AA86C")
            .radius(4)
            .onClick(e -> {
                onConfirm.run();
                api.closeWindow(e.player(), "confirm");
            });

    window.addButton("btn_cancel", 140, 80, 100, 22, "取消")
            .backgroundColor("#FF3A4356")
            .hoverColor("#FF4A5568")
            .radius(4)
            .onClick(e -> api.closeWindow(e.player(), "confirm"));

    api.openWindow(player, window);
}
```

### 事件回调

| action | value | 触发时机 |
| --- | --- | --- |
| `click` | 无 | 鼠标左键点击按钮矩形内任意位置（拖动组内需未发生拖动） |

## 3.5 ImageWidget

### 用途

显示通过 `GuiApi.registerImage(imageId, bytes)` 注册到客户端的图片，可整块点击，适合卡牌、图标按钮、全屏背景。

### 构造 / 工厂方法

```java
ImageWidget addImage(String id, int x, int y, int width, int height, String imageId)
```

`imageId` 是注册时使用的名字；打开窗口时插件会自动把窗口引用到的图片发给客户端。若稍后通过 `updateWidget` 换成一张没发过的图，请先调用 `GuiApi.preloadImage(player, imageId)`（详见 [06-图片与音效](06-图片与音效.md)）。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `ImageWidget image(String imageId)` | 换图片 | 已注册的图片 id | 只改引用，不会发送图片数据 |
| `ImageWidget fit(String fit)` | 缩放方式 | `"stretch"`（默认，拉伸铺满）、`"cover"`（铺满并裁切）、`"contain"`（完整显示并留边） | 传入其他值按 `stretch` 处理 |
| `ImageWidget onClick(Consumer<GuiActionEvent> handler)` | 点击回调 | 回调 | 设置后整块图片可点击并带悬停高亮 |

只读方法：`imageId()`、`clickHandler()`。

### 示例

```java
void openCard(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("card_demo").size(260, 240).titleBar(false);

    window.addImage("backdrop", 0, 0, 0, 0, "card_table")
            .fit("cover")
            .widthPercent(100)
            .heightPercent(100);

    window.addImage("card", 0, 0, 0, 0, "card_bomb")
            .fit("contain")
            .onClick(e -> e.player().sendMessage("选中炸弹牌"))
            .aspect(160.0 / 225.0)
            .widthPercent(45)
            .xPercent(27.5)
            .yPercent(12)
            .hoverLift(true);

    window.addImage("back", 0, 0, 0, 0, "card_back")
            .fit("contain")
            .onClick(e -> e.player().sendMessage("选中牌堆"))
            .aspect(160.0 / 225.0)
            .widthPercent(45)
            .xPercent(27.5)
            .yPercent(12);

    api.openWindow(player, window);
}
```

### 事件回调

| action | value | 触发时机 |
| --- | --- | --- |
| `click` | 无 | 点击图片矩形；仅当调用了 `onClick(...)` |

## 3.6 基础控件速查

| 控件 | 工厂方法 | 可点击 | action | value |
| --- | --- | --- | --- | --- |
| `Panel` | `addPanel(id, x, y, w, h)` | 调用 `onClick` 后 | `click` | 无 |
| `Label` | `addLabel(id, x, y, text)` | 否 | — | — |
| `Button` | `addButton(id, x, y, w, h, text)` | 是 | `click` | 无 |
| `ImageWidget` | `addImage(id, x, y, w, h, imageId)` | 调用 `onClick` 后 | `click` | 无 |

表单类控件（输入框、滑块、勾选、单选、下拉、物品）见 [04-表单控件](04-表单控件.md)；事件模型、回调参数与 `updateWidget` 可改属性见 [05-事件与交互](05-事件与交互.md)。
