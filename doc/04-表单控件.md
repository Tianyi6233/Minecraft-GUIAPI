# 04 · 表单控件

本章覆盖需要用户输入或选择的控件：`TextField`、`Slider`、`Scrollbar`、`Checkbox`、`Radio`、`Dropdown`、`ItemWidget`。所有回调都在服务端主线程触发，`GuiActionEvent` 的完整说明见 [05-事件与交互](05-事件与交互.md)；控件通用能力（坐标、百分比、`visible`、`tooltip`、`glow`、`hoverLift`、`anim`、`dragGroup` 及链式调用陷阱）见 [03-基础控件](03-基础控件.md)。

> 示例默认已导入：`com.guiapi.paper.GuiApi`、`com.guiapi.paper.GuiWindow`、`com.guiapi.paper.widget.*`、`org.bukkit.entity.Player`。

## 4.1 TextField

### 用途

单行文本输入框。客户端在本地接收键盘输入，按 Enter 或失去焦点时把最终文本发给服务端；开启 `live` 后每次击键都会发送。

### 构造 / 工厂方法

```java
TextField addTextField(String id, int x, int y, int width, int height)
```

宽高由调用方指定。输入框被点击后获得焦点，Esc / Enter 都会提交内容并取消焦点。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `TextField text(String text)` | 初始文本 | 文本，`null` 按 `""` | 默认 `""` |
| `TextField placeholder(String placeholder)` | 空内容时的提示文字 | 文本 | 默认 `""`；只显示，不会作为值提交 |
| `TextField maxLength(int maxLength)` | 最大长度 | 字符数，默认 `64` | 小于 1 按 1 处理；客户端截断输入 |
| `TextField backgroundColor(String hex)` | 背景色 | `"#RRGGBB"` / `"#AARRGGBB"` | 不设置则用主题默认色 |
| `TextField backgroundColor(int argb)` | 背景色 | ARGB 整数 | — |
| `TextField borderColor(String hex)` | 边框色 | 同上 | 不设置则用主题默认色 |
| `TextField borderColor(int argb)` | 边框色 | ARGB 整数 | — |
| `TextField textColor(String hex)` | 文字颜色 | 同上 | 不设置则默认白色 |
| `TextField textColor(int argb)` | 文字颜色 | ARGB 整数 | — |
| `TextField live(boolean live)` | 实时上报 | `true` 每次击键都发 | 默认 `false`；默认只在 Enter / 失焦时发送 |
| `TextField onChange(Consumer<GuiActionEvent> handler)` | 内容变化回调 | 回调 | 在 Enter、失焦或 live 击键时触发 |

只读方法：`text()`、`live()`、`changeHandler()`。

### 示例

```java
void openRename(Player player) {
    GuiApi api = GuiApi.get();
    java.util.concurrent.atomic.AtomicReference<String> input =
            new java.util.concurrent.atomic.AtomicReference<>("");

    GuiWindow window = new GuiWindow("rename_demo").title("修改名字").size(280, 140);

    window.addTextField("name", 20, 30, 240, 22)
            .placeholder("输入新名字")
            .maxLength(16)
            .live(true)
            .onChange(e -> {
                input.set(e.valueAsString());
                e.player().sendMessage("当前输入：" + e.valueAsString());
            });

    window.addButton("ok", 20, 80, 80, 20, "确定")
            .onClick(e -> {
                if (input.get().isBlank()) {
                    e.player().sendMessage("名字不能为空");
                    return;
                }
                e.player().sendMessage("新名字：" + input.get());
                api.closeWindow(e.player(), "rename_demo");
            });

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `text` | `String` | Enter / Esc 提交、点击输入框外部导致失焦、或 `live(true)` 时每次击键 |

事件到来时服务端会先把该 `TextField` 对象的 `text(...)` 更新为最新值，再调用 `onChange`。注意 action 字符串是 `text`，不是 `change`。

## 4.2 Slider

### 用途

水平滑块。拖动时客户端只更新本地显示，松开鼠标时把最终数值发给服务端。

### 构造 / 工厂方法

```java
Slider addSlider(String id, int x, int y, int width)
```

高度固定为 `20`（上方 12 像素为文字，下方为轨道）。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Slider min(double min)` | 最小值 | 默认 `0` | 应小于 `max` |
| `Slider max(double max)` | 最大值 | 默认 `100` | — |
| `Slider step(double step)` | 步长 | 默认 `1` | 拖动结果按步长取整；`<= 0` 时不取整（连续值） |
| `Slider value(double value)` | 初始值 | 默认 `0` | 客户端显示时按 min/max 夹取 |
| `Slider label(String label)` | 数值前缀 | 文本，默认 `""` | 显示为 `label: 数值`；为空时只显示数值 |
| `Slider onChange(Consumer<GuiActionEvent> handler)` | 数值变化回调 | 回调 | 松开鼠标时触发一次 |

只读方法：`min()`、`max()`、`step()`、`value()`、`label()`、`changeHandler()`。

### 示例

```java
void openBuy(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("buy_demo").title("购买").size(300, 160);

    window.addLabel("qty_text", 20, 20, "数量：1").color("#C8D2E0");

    window.addSlider("qty", 20, 44, 260)
            .min(1)
            .max(64)
            .step(1)
            .value(1)
            .label("数量")
            .onChange(e -> api.updateWidget(e.player(), "buy_demo", "qty_text",
                    Map.of("text", "数量：" + (int) e.valueAsDouble())));

    window.addButton("ok", 20, 100, 100, 20, "确认")
            .onClick(e -> {
                e.player().sendMessage("已购买");
                api.closeWindow(e.player(), "buy_demo");
            });

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `change` | `double` | 松开滑块时发送最终值 |

事件到来时服务端会先更新该 `Slider` 对象的 `value(...)`，再调用 `onChange`。拖动过程中不会发送数据包，因此不要在拖动途中依赖回调更新其他控件。

## 4.3 Checkbox

### 用途

带文字的复选框，适合开关类选项。

### 构造 / 工厂方法

```java
Checkbox addCheckbox(String id, int x, int y, String label, boolean checked)
```

高度固定为 `12`；点击判定区域为左侧 12 像素方框加文字宽度（`16 + 文字宽度`，高 12）。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Checkbox label(String label)` | 右侧文字 | 文本 | 构造时必传，之后可改 |
| `Checkbox checked(boolean checked)` | 勾选状态 | `true` 选中 | 默认取构造参数 |
| `Checkbox onToggle(Consumer<GuiActionEvent> handler)` | 切换回调 | 回调 | 点击时触发一次 |

只读方法：`label()`、`checked()`、`toggleHandler()`。

### 示例

```java
void openOptions(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("options_demo").title("选项").size(280, 140);

    window.addLabel("state", 20, 16, "PVP：关").color("#C8D2E0");

    window.addCheckbox("pvp", 20, 40, "允许 PVP", false)
            .onToggle(e -> api.updateWidget(e.player(), "options_demo", "state",
                    Map.of("text", "PVP：" + (e.valueAsBoolean() ? "开" : "关"))));

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `toggle` | `boolean` | 点击复选框，`value` 为切换后的状态 |

事件到来时服务端会先把该 `Checkbox` 对象的 `checked(...)` 更新为新状态，再调用 `onToggle`。

## 4.4 Radio

### 用途

单选按钮。同一窗口内 `group` 相同的单选框互斥：点击一个，客户端自动把同组其他单选框取消勾选。

### 构造 / 工厂方法

```java
Radio addRadio(String id, int x, int y, String label, String group, boolean checked)
```

高度固定为 `12`；点击判定区域与 `Checkbox` 相同（`16 + 文字宽度` × 12）。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Radio label(String label)` | 右侧文字 | 文本 | — |
| `Radio group(String group)` | 所属分组 | 组名 | 同组互斥；不要传 `null`，空组名也会被视为同一组 |
| `Radio checked(boolean checked)` | 勾选状态 | `true` 选中 | 同一组建议只给一个传 `true` |
| `Radio onToggle(Consumer<GuiActionEvent> handler)` | 选中回调 | 回调 | 仅被点击的那个单选框会触发 |

只读方法：`label()`、`group()`、`checked()`、`toggleHandler()`。

注意：客户端自动取消同组其他单选框的勾选，但这种“取消”不会逐个发给服务端。服务端其他 `Radio` 对象的 `checked()` 不会自动变化；如需保持一致，请在回调里用 `updateWidget(..., Map.of("checked", false))` 同步同组其他控件，或自行用变量记录当前选项。

### 示例

```java
void openDifficulty(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("diff_demo").title("难度").size(280, 180);

    window.addLabel("result", 20, 16, "当前难度：简单").color("#C8D2E0");

    window.addRadio("easy", 30, 40, "简单", "difficulty", true)
            .onToggle(e -> api.updateWidget(e.player(), "diff_demo", "result",
                    Map.of("text", "当前难度：简单")));

    window.addRadio("normal", 30, 62, "普通", "difficulty", false)
            .onToggle(e -> api.updateWidget(e.player(), "diff_demo", "result",
                    Map.of("text", "当前难度：普通")));

    window.addRadio("hard", 30, 84, "困难", "difficulty", false)
            .onToggle(e -> api.updateWidget(e.player(), "diff_demo", "result",
                    Map.of("text", "当前难度：困难")));

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `toggle` | `boolean`（恒为 `true`） | 点击某个单选框，使其成为选中项 |

服务端不会自动修改任何 `Radio` 对象的 `checked()`，需要自行维护状态。

## 4.5 Dropdown

### 用途

下拉列表。点击收起框展开选项，选中一项后通知服务端。展开列表最多同时显示 6 行，超过时可用鼠标滚轮滚动。

### 构造 / 工厂方法

```java
Dropdown addDropdown(String id, int x, int y, int width, List<String> options)
```

收起状态高度默认 `18`。`options` 为 `null` 时按空列表处理。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Dropdown options(List<String> values)` | 替换全部选项 | 选项文本列表 | `null` 按空列表处理；若当前 `selected` 越界会重置为 0 |
| `Dropdown selected(int selected)` | 当前选中下标 | 从 0 开始 | 越界时收起框显示空字符串；建议始终传有效下标 |
| `Dropdown height(int px)` | 收起框高度 | 像素，默认 `18` | 小于 12 按 12 处理；字号较大时一起调高 |
| `Dropdown rowHeight(int px)` | 展开后每行高度 | 像素，默认 `16` | 小于 10 按 10 处理 |
| `Dropdown onSelect(Consumer<GuiActionEvent> handler)` | 选中回调 | 回调 | 选中某项时触发 |

只读方法：`options()`、`selected()`、`height()`、`rowHeight()`、`selectHandler()`。

展开后的列表以 MC 风格绘制（深色面板 + 黑边 + 选中行高亮），高度按 `rowHeight` 计算，超出窗口时仍可溢出显示。

### 示例

```java
void openFruit(Player player) {
    GuiApi api = GuiApi.get();
    List<String> fruits = List.of("苹果", "香蕉", "橙子");
    GuiWindow window = new GuiWindow("fruit_demo").title("水果").size(280, 160);

    window.addLabel("sel", 20, 16, "当前选择：苹果").color("#C8D2E0");

    window.addDropdown("fruit", 20, 40, 200, fruits)
            .selected(0)
            .onSelect(e -> {
                int index = e.valueAsInt();
                String label = fruits.get(index);
                e.player().sendMessage("选择：" + label);
                api.updateWidget(e.player(), "fruit_demo", "sel",
                        Map.of("text", "当前选择：" + label));
            });

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `select` | `int`（选项下标，从 0 开始） | 在展开列表中点击某一项 |

**取值说明**：事件里的 `value` 是下标，不是选项文本。`valueAsString()` 只会得到下标的字符串形式（例如 `"2"`），不要拿它当选项文本。正确写法是用 `valueAsInt()` 去查 `options` 列表，如示例所示。

事件到来时服务端会先更新该 `Dropdown` 对象的 `selected(...)`，再调用 `onSelect`。

## 4.6 Scrollbar

### 用途

垂直滚动条。用于「内容多于可视区」的场景：滚动条本身不移动任何控件，只负责上报 `0–100` 的数值，由服务端在回调里换算偏移量并 `updateWidget` 刷新内容。

支持三种操作：拖动滑块、点击轨道翻页、在滚动条上滚轮。

### 构造 / 工厂方法

```java
Scrollbar addScrollbar(String id, int x, int y, int width, int height)
```

宽高完全由调用方指定；常见宽度为 `10`–`14`，高度为内容区的可视高度。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `Scrollbar value(double value)` | 初始位置 | `0`–`100` | 默认 `0`（顶部） |
| `Scrollbar thumb(double percent)` | 滑块高度占比 | 百分比 | 默认 `20`；建议按 `可视条数 / 总条数 × 100` 计算 |
| `Scrollbar live(boolean live)` | 拖动中实时回传 | 默认 `true` | 关掉后只在松手时回调一次；数据量大时更省包 |
| `Scrollbar trackColor(String hex)` | 轨道颜色 | `"#RRGGBB"` / `"#AARRGGBB"` | 不设置用默认深灰 |
| `Scrollbar trackColor(int argb)` | 轨道颜色 | ARGB 整数 | — |
| `Scrollbar thumbColor(String hex)` | 滑块颜色 | 同上 | 不设置用默认浅灰 |
| `Scrollbar thumbColor(int argb)` | 滑块颜色 | ARGB 整数 | — |
| `Scrollbar onChange(Consumer<GuiActionEvent> handler)` | 数值变化回调 | 回调 | 拖动中按约 60ms 节流上报，松手时补发最终值 |

只读方法：`value()`、`thumb()`、`live()`、`changeHandler()`。

### 示例

30 条数据、可视 6 条，用滚动条翻页：

```java
void openList(Player player) {
    GuiApi api = GuiApi.get();
    List<String> items = List.of("01 · 苹果", /* … */ "30 · 桑葚");
    final int visible = 6;

    GuiWindow window = new GuiWindow("list_demo").title("列表").size(240, 212);

    for (int i = 0; i < visible; i++) {
        window.addLabel("row" + i, 14, 30 + i * 20, items.get(i));
    }

    window.addScrollbar("bar", 206, 28, 12, 120)
            .thumb(100.0 * visible / items.size())   // 6/30 = 20%
            .value(0)
            .onChange(e -> {
                int offset = (int) Math.round(e.valueAsDouble() / 100.0 * (items.size() - visible));
                for (int i = 0; i < visible; i++) {
                    api.updateWidget(e.player(), "list_demo", "row" + i,
                            Map.of("text", items.get(offset + i)));
                }
            });

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `change` | `double`（`0`–`100`） | 拖动滑块（`live` 时按约 60ms 节流）、点击轨道、滚轮，以及松手时的最终值 |

事件到来时服务端会先更新该 `Scrollbar` 对象的 `value(...)`，再调用 `onChange`。偏移量换算公式固定为 `offset = round(value / 100 * (总数 - 可视数))`，不要在客户端侧假设像素滚动。

## 4.7 ItemWidget

### 用途

在窗口里显示一个原版 Minecraft 物品图标，带数量、自定义名称、lore、附魔信息与点击事件。适合商店、背包、奖励列表。

### 构造 / 工厂方法

```java
ItemWidget addItem(String id, int x, int y, int width, int height, String material)
ItemWidget addItem(String id, int x, int y, int width, int height, org.bukkit.Material material)
```

`material` 支持 Bukkit `Material` 枚举，也支持原版 id 字符串，例如 `"DIAMOND_SWORD"` 或 `"minecraft:diamond_sword"`（大小写不敏感）。物品图标会按格子大小自动放大，最多 4 倍。

### 链式方法

| 方法签名 | 作用 | 参数 | 注意 |
| --- | --- | --- | --- |
| `ItemWidget material(org.bukkit.Material material)` | 设置物品 | Bukkit 枚举 | 取枚举的 `name()` |
| `ItemWidget material(String material)` | 设置物品 | 原版 id 字符串 | 大小写不敏感；无效 id 显示 `?` |
| `ItemWidget amount(int amount)` | 堆叠数量 | `1`–`64`，默认 `1` | 超出范围自动夹到 1–64；数量大于 1 时右下角显示数字 |
| `ItemWidget displayName(String displayName)` | 自定义名称 | 文本 | 不设置时使用物品的原版本地化名称 |
| `ItemWidget lore(List<String> lore)` | 说明行 | 文本列表 | `null` 表示无 lore；空列表也不显示 |
| `ItemWidget enchants(List<String> enchants)` | 附魔行 | 每项格式 `"<翻译键>:<等级>"`，如 `"enchantment.minecraft.sharpness:5"` | 客户端按玩家语言翻译；`null` 表示无 |
| `ItemWidget enchanted(boolean enchanted)` | 附魔光效 | `true` 显示闪光 | 纯视觉，默认 `false` |
| `ItemWidget onClick(Consumer<GuiActionEvent> handler)` | 点击回调 | 回调 | 整个物品格子都可点击 |

只读方法：`material()`、`amount()`、`displayName()`、`lore()`、`enchants()`、`enchanted()`、`clickHandler()`。

物品的悬停提示由物品信息自动生成（名称 + 附魔 + lore），会覆盖通用的 `tooltip(...)`；只有物品无法解析时才会回退到普通提示。

### 示例

```java
void openItemShop(Player player) {
    GuiApi api = GuiApi.get();
    GuiWindow window = new GuiWindow("item_demo").title("物品").size(320, 180);

    window.addItem("diamond", 20, 30, 40, 40, Material.DIAMOND)
            .amount(16)
            .displayName("钻石")
            .lore(List.of("用于交易", "点击出售"))
            .onClick(e -> e.player().sendMessage("出售钻石"));

    window.addItem("sword", 80, 30, 40, 40, "minecraft:diamond_sword")
            .displayName("锋利之剑")
            .enchants(List.of("enchantment.minecraft.sharpness:5"))
            .enchanted(true)
            .onClick(e -> e.player().sendMessage("装备剑"));

    window.addItem("star", 140, 30, 40, 40, Material.NETHER_STAR)
            .displayName("下界之星")
            .tooltip("稀有物品");

    api.openWindow(player, window);
}
```

### 事件回调

| action | value 类型 | 触发时机 |
| --- | --- | --- |
| `click` | 无 | 点击物品格子内任意位置 |

物品格子始终会消费点击；没有设置 `onClick` 时点击不会产生任何效果。

## 4.8 表单控件事件速查

| 控件 | 工厂方法 | 回调注册 | action | value |
| --- | --- | --- | --- | --- |
| `TextField` | `addTextField(id, x, y, w, h)` | `onChange` | `text` | `String` |
| `Slider` | `addSlider(id, x, y, w)` | `onChange` | `change` | `double` |
| `Scrollbar` | `addScrollbar(id, x, y, w, h)` | `onChange` | `change` | `double`（`0`–`100`） |
| `Checkbox` | `addCheckbox(id, x, y, label, checked)` | `onToggle` | `toggle` | `boolean` |
| `Radio` | `addRadio(id, x, y, label, group, checked)` | `onToggle` | `toggle` | `boolean`（恒为 `true`） |
| `Dropdown` | `addDropdown(id, x, y, w, options)` | `onSelect` | `select` | `int`（下标） |
| `ItemWidget` | `addItem(id, x, y, w, h, material)` | `onClick` | `click` | 无 |

事件对象 `GuiActionEvent` 的取值方法、`updateWidget` 可改属性、窗口关闭与 Esc 行为，见 [05-事件与交互](05-事件与交互.md)。
